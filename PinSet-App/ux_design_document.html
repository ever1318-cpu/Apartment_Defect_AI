2 화면별 상세 UX/UI 설계
S01 스플래시 / 앱 로딩

앱 최초 진입 시 브랜드 아이덴티티를 전달하고 초기 데이터(평면도 캐시, 사용자 설정)를 로드합니다.

  • 앱 아이콘 + 브랜드명 '하자체크' 중앙 표시
  • 0.5x / 2x 듀얼 렌즈 심볼 아이콘
  • 하단 프로그레스 바 (로딩 진행률)
  • 자동 전환: 기존 사용자 → S03, 신규 → S02
자동 전환 캐시 로드
S02 세대 정보 입력

단지명, 동, 호수를 입력하면 해당 세대의 평면도를 서버에서 로드하여 캐싱합니다.

  • 단지명 자동완성 검색 (API 연동)
  • 동/호수 드롭다운 + 직접 입력
  • 평면도 미리보기 카드 (로드 완료 시 표시)
  • 평면도 로드 실패 시 수동 업로드 옵션
  • 입력 완료 후 '점검 시작하기' 버튼 활성화
폼 입력 API 연동
S03 메인 홈 대시보드

현재 점검 세션의 전체 현황을 한눈에 파악하고, 새 하자 촬영을 빠르게 시작할 수 있는 허브 화면입니다.

  • 세대 정보 + 점검 통계 요약 카드
  • 전체/미승인/완료 건수 실시간 표시
  • ⚡ 새 하자 촬영 시작 CTA 버튼 (핑크/레드)
  • 최근 하자 목록 (썸네일 + 분류 + 심각도)
  • 하단 탭바: 홈 / 평면도 / 목록 / 보고서
탭 네비게이션 실시간 통계
S04 ⚡ 원샷 듀얼 캡처 카메라

핵심 화면. 0.5x 초광각(위치 파악)과 2x 망원(하자 분석) 렌즈를 동시에 프리뷰하고, 셔터 1회로 두 장을 동시 캡처합니다.

  • 상단 60%: 0.5x 초광각 실시간 프리뷰 (노란 테두리)
  • 하단 40%: 2x 망원 실시간 프리뷰 (빨간 테두리)
  • 중간 구분바: ISP 동기화 상태 표시 (초록 점)
  • 셔터 버튼 1회 탭 → 2장 하드웨어 동기화 캡처
  • 흔들림/저조도 감지 시 경고 오버레이 표시
  • iOS: AVCaptureMultiCamSession / Android: Camera2 API
원샷 듀얼 캡처 ISP 동기화 탭 제스처
S05 스냅 확인 (촬영 완료)

촬영된 두 장의 사진을 나란히 보여주어 품질을 확인하고, 분석 진행 또는 재촬영을 선택합니다.

  • 0.5x 사진 (좌) + 2x 사진 (우) 나란히 표시
  • 각 사진에 품질 상태 아이콘 (정상/흔들림/어두움)
  • ISP 동기화 완료 확인 배지
  • '분석 시작' 버튼 (파란색, 메인 CTA)
  • '재촬영' 버튼 (회색, 보조 CTA)
확인/취소 품질 검증
S06 AI 분석 로딩

두 장의 사진을 서버로 전송하고 AI 분석이 진행되는 동안 단계별 진행 상태를 시각적으로 표시합니다.

  • 상단: 촬영된 두 사진 미니 썸네일
  • 중앙: AI 뇌/칩 아이콘 + '분석 중...' 텍스트
  • 진행률 바 (0% → 100%)
  • 단계별 체크리스트: 이미지 전송 → 2x 분류 → 0.5x 위치 추정
  • 평균 소요 시간 안내 (3~5초)
멀티모달 AI 서버 통신
S07 AI 분류 결과

AI가 분류한 하자 유형, 신뢰도, 심각도를 표시하고 사용자가 수정하거나 평면도에 표시할 수 있습니다.

  • 주 분류 결과 카드 (하자 유형 + 신뢰도 %)
  • 심각도 선택 (중대/보통/경미) 라디오 버튼
  • 대안 분류 2개 (신뢰도 낮은 순) 선택 가능
  • 메모 추가 텍스트 입력 (500자)
  • '평면도에 표시하기' 버튼 → S08 이동
  • 90% 이상 시 일괄 승인 배너 표시
신뢰도 표시 수동 수정 일괄 승인
S08 평면도 상세보기 → 하자부위 상세 보기

AI가 추정한 위치에 하자 핀이 자동 표시되며, 사용자가 드래그로 미세 조정하거나 수동 핀을 추가할 수 있습니다.

  • 전체 평면도 + 기존 하자 핀 표시
  • 신규 핀: 빨간 'A' 배지 + 펄싱 애니메이션
  • 핀 드래그로 위치 미세 조정 가능
  • 빈 공간 탭 → 수동 핀 추가 ('M' 배지)
  • 핀 탭 → 하단 시트에 상세 정보 표시
  • 핀 색상: 중대(빨강) / 보통(주황) / 경미(초록)
드래그 이동 탭 추가 AI 자동 위치 핀 관리
S09 핀 상세 정보 모달

특정 핀을 탭하면 하단에서 올라오는 바텀 시트 모달로 해당 하자의 모든 정보를 확인하고 수정합니다.

  • 0.5x 위치사진 + 2x 하자사진 나란히 표시
  • 사진 탭 시 전체화면 확대 뷰어
  • 하자 유형, 세부 분류, 심각도, 위치, 신뢰도
  • 점검 일시, 메모 전문 표시
  • 감지 방법: 'AI 자동' 또는 '수동 입력' 배지
  • '수정하기' / '삭제하기' 버튼
바텀 시트 핀치 줌 CRUD
S10 점검 완료 보고서

전체 점검 결과를 요약하고 PDF 보고서로 내보내거나 공유할 수 있는 최종 화면입니다.

  • 점검 완료 성공 배너 (세대 정보 포함)
  • 전체/중대/보통/경미 건수 통계 카드
  • 하자 유형별 분포 가로 막대 차트
  • 전체 핀이 표시된 평면도 미니맵
  • '미리보기' / 'PDF·이메일 공유' 버튼
  • '새 하자 추가' 버튼 → S04 복귀
PDF 내보내기 공유 통계 차트
3 핵심 인터랙션 흐름 — 원샷 듀얼 캡처 → AI 분석 → 평면도 매핑

⚡ 원샷 듀얼 캡처부터 평면도 핀 저장까지 (약 15~20초)

1
카메라 화면 진입 (S04)
앱이 iOS AVCaptureMultiCamSession / Android Camera2 API를 초기화하여 0.5x 초광각과 2x 망원 렌즈를 동시에 활성화합니다. 상하 분할 프리뷰가 실시간으로 표시됩니다.
AVCaptureMultiCamSession / Camera2 Logical Multi-Camera
2
셔터 버튼 1회 탭
ISP(이미지 신호 처리기) 하드웨어 클럭 기준으로 두 렌즈가 동시에 캡처됩니다. 소프트웨어 타이머가 아닌 하드웨어 동기화이므로 두 사진의 타임스탬프가 완벽히 일치합니다.
Hardware ISP Timestamp Sync
3
스냅 확인 (S05)
두 장의 사진이 나란히 표시됩니다. 흔들림·저조도 자동 감지 알고리즘이 품질을 검증하고, 문제가 있으면 재촬영을 권고합니다. 사용자가 '분석 시작'을 탭합니다.
Blur Detection / Exposure Check
4
AI 분석 서버 전송 (S06)
두 장의 사진이 멀티파트 폼으로 서버에 전송됩니다. 서버는 두 사진을 멀티모달 Vision AI(GPT-4o 또는 Claude 3.5)에 동시에 전달하는 프롬프트를 구성합니다.
Multimodal Vision API (GPT-4o / Claude 3.5)
5
AI 이중 분석 실행
2x 망원 사진 → 하자 유형(균열/누수/마감불량 등), 세부 분류, 심각도, 신뢰도 산출. 0.5x 초광각 사진 → 공간 랜드마크(문, 창문, 벽 교차점) 추출 후 평면도와 매칭하여 위치 좌표(x, y) 추정.
Z-FLoc (Zero-Shot Floorplan Localization)
6
분류 결과 확인 및 수정 (S07)
AI 분류 결과와 신뢰도가 표시됩니다. 신뢰도 90% 이상이면 일괄 승인 배너가 표시됩니다. 사용자는 대안 분류를 선택하거나 메모를 추가할 수 있습니다.
Confidence Score Threshold: 90%
7
평면도 핀 자동 표시 (S08)
AI가 추정한 (x, y) 정규화 좌표에 하자 핀이 자동으로 표시됩니다. 핀에는 'A'(AI 자동) 배지와 펄싱 애니메이션이 적용됩니다. 사용자는 드래그로 위치를 미세 조정합니다.
Normalized Coordinate (0~1) Storage
8
핀 저장 및 다음 하자 촬영
핀 좌표와 하자 정보가 데이터베이스에 저장됩니다. 사용자는 S04로 돌아가 다음 하자를 촬영하거나, S10 보고서 화면으로 이동합니다.
PostgreSQL / tRPC API

🍎 iOS 지원

최소 요구사항: iPhone XS 이상, iOS 13+

듀얼 캡처 지원: iPhone 11 Pro 이상 (0.5x + 2x 물리 렌즈 조합)
