AI하자점검 카메라 각도기반 5부위 분류 설계서 v1.0

핵심 원칙: 카메라 기울기만으로 구분하지 않고, 센서+이미지+AI 신뢰도를 결합한다. 불확실하면 자동 확정하지 않고 점검자에게 5개 후보를 제시한다.

1. 5부위 구분 기준

부위카메라 피치 기준(초기값)이미지 교차 확인
천장위를 보는 각도, -55도 이하상단 평면, 조명·천장판·각축 특징
천장-벽-55도 ~ -20도천장과 벽이 만나는 선, 코너 특징
벽-20도 ~ +20도수직 벽면, 창호·문틀·콘센트 특징
벽-바닥+20도 ~ +55도걸레받이·벽지 하단·바닥 접합선
바닥아래를 보는 각도, +55도 이상바닥 평면, 타일·마루·배수구 특징

각도는 기기 종류와 점검자의 자세에 따라 달라지므로, 초기 파일럿에서는 위 범위를 시작값으로 쓰고 현장 샘플로 보정한다.

2. 추천 분류 방식

IMU 피치(기울기) 40% + 이미지 평면/경계 모델 45% + 카메라 초점·거리 보조정보 15% → Top-2 부위 후보
  1. 클릭 시점의 피치·롤·방위를 최소 0.5초 평균으로 저장한다.
  2. 이미지 모델은 천장, 벽, 바닥 평면과 접합선을 검출한다.
  3. 센서와 이미지가 같으면 자동 선택, 다르면 신뢰도를 낮추고 Top-2 풀다운으로 제시한다.
  4. 신뢰도 0.75 미만이면 ‘자동 추정?으로만 표시하고 점검자 확정을 필수로 한다.

3. 현장 UX

  • 상세부위 제목은 거실/벽처럼 간단히 표시한다.
  • 부위 후보는 최대 2개만 보이고, 추천 상세부위는 최대 5개를 풀다운으로 제공한다.
  • ‘모르겠음’은 자유의견으로 남기고, 추후 AI 추천과 관리자 검수로 확정한다.

4. 학습 및 보정

품질점검 사진에 ‘부위 5종’을 별도 라벨로 추가하고, 사진·IMU·점검자 최종선택을 함께 모은다. 현장에서 수정된 부위는 재학습용 Gold 라벨로 승격시킨다.
