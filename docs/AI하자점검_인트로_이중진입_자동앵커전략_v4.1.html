인트로 이중 진입·자동 앵커 전략

버전 4.1 · 2026-07-25

1. 인트로 하단 진입

앵커 촬영
✨ 하자 입력

기존 단일 앵커 촬영 버튼을 명시적인 두 작업 경로로 분리했다.

2. 하자 입력 직행

하자 입력 → 앵커 기준 선택 → LIVE DETECTION 하자 촬영 → 위치·이미지 확인 → 의견·AI 분류
1. 거실 중앙평면도 메타데이터의 거실 중앙 좌표를 즉시 세션 앵커로 저장
2. 최초 하자 위치앵커 좌표를 비워 두고 첫 하자 핀의 최종 확정 위치를 세션 앵커로 저장

3. 데이터 일관성

  • 두 직접 입력 전략 모두 활성 세대·평면도·공간 컨텍스트 저장
  • 거실 중앙은 anchorLocationLabel=거실 중앙으로 구분
  • 최초 하자 위치는 첫 결함 저장 시 방향과 좌표를 함께 기록
  • 홈·라이브 평면도·하자 경로에서 두 전략을 정상 앵커로 인식
