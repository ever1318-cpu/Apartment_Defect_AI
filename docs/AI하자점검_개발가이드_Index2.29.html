PostgreSQL read-only 추출, 자격증명 없는 Colab ZIP 생성, Google Colab GPU 학습, 결과 ZIP 검증·회수 흐름을 준비했습니다. Colab이 RDS에 직접 접속하지 않으므로 DB 비밀번호와 네트워크 접근을 노트북에 노출하지 않습니다.

3. PC에서 실행: 우선 2만장 Pilot

RDS 접속 환경변수가 현재 PowerShell에 설정된 상태에서 프로젝트 루트에서 실행합니다. 기본값은 20,000장 Pilot이며, 기존 출력 폴더는 절대 덮어쓰지 않습니다.

cd D:\AI_projects\Apartment_Defect_AI
.\scripts\prepare_expert_quality_colab_bundle.ps1 -Limit 20000

성공하면 다음 ZIP 두 개가 생성됩니다.

workspace\colab-input\expert-quality-convnext-colab.zip
workspace\colab-input\expert-quality-convnext-colab.zip.sha256
전체 eligible 데이터를 사용할 때만 -Limit 0을 사용합니다. 처음부터 전체 11만여 장을 내려받으면 Colab 세션 시간·Drive 용량·이미지 URL 실패율을 먼저 확인해야 하므로 Pilot 성공 후 진행하는 것이 안전합니다.

4. Google Drive와 Colab에서 실행

  1. ZIP과 같은 이름의 .sha256 파일을 Google Drive의 MyDrive/Apartment_Defect_AI/colab-input/에 함께 올립니다.
  2. 새 노트북 파일을 Colab으로 업로드하거나 Drive에서 열고, 런타임을 T4 GPU 이상으로 변경합니다.
  3. 두 번째 코드 셀의 BUNDLE_NAME이 업로드한 ZIP 이름과 같은지 확인합니다.
  4. 위에서 아래 순서대로 모든 셀을 실행합니다.
  5. 다운로드 실패율이 2%를 넘으면 학습을 중단하고 URL 접근·파일 권한을 점검합니다.
  6. 학습 결과 ZIP과 SHA-256 파일이 MyDrive/Apartment_Defect_AI/colab-results/에 생성됩니다.

5. 이번 학습 설정

모델ImageNet 사전학습 ConvNeXt-Tiny
분류 과제area, part, part_detail, work_kind, cause
GPU 설정12 epochs · batch 32 · learning rate 0.0001

원인과 공종은 사진만으로 자동확정하지 않습니다. 모델은 후보 Top-3를 제시하고, 실제 앱에서는 점검자 설명·계측값·유사사례를 함께 사용해 전문가가 확정합니다.

6. 결과를 PC로 회수하고 판정

Drive에서 결과 ZIP과 SHA-256을 PC로 가져온 뒤, 결과를 검증·가져옵니다.

cd D:\AI_projects\Apartment_Defect_AI
.\.venv\Scripts\apartment-data.exe vision-colab-import `
  "<다운로드한 결과 ZIP 경로>" `
  "workspace\datasets\expert-quality-colab-run-20260803"

반드시 확인할 값은 각 분류 축의 Top-1, Top-3, Macro-F1, 레이블별 표본 수입니다. 특히 상세부위와 원인의 Macro-F1이 낮으면, 단순 정확도만 보고 배포하지 않습니다.

7. 앱 연결 전 승인 기준
