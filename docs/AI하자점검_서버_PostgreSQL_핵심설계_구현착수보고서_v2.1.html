3. 이번 구현

  • database/migrations/001_apartment_ai_core.sql: 전용 apartment_ai 스키마, 12개 테이블·제약·인덱스
  • postgres_inspection_store.py: 세션 생성과 하자 upsert 트랜잭션
  • 파라미터 SQL만 사용하고 DSN·비밀번호를 SQL·오류에 포함하지 않음
  • Idempotency-Key 재사용, 동일 client UUID, revision 충돌 처리
  • 입주민 RAW 의견과 표준화 의견 및 최종 분류를 별도 컬럼으로 분리
  • 운영 AWS RDS에는 DDL·INSERT·UPDATE를 실행하지 않음

6. 운영 적용 원칙

  • 운영 RDS 적용 전 전용 DB 사용자와 최소 권한을 만든다.
  • 마이그레이션은 자동 실행하지 않고 버전·백업·승인 후 수행한다.
  • 이미지 바이너리는 PostgreSQL이 아니라 객체 스토리지에 저장하고 DB에는 검증된 키와 해시만 보관한다.
  • 개인정보와 입주민 의견은 전송·저장 암호화, 접근 감사, 보존기간 정책을 적용한다.
