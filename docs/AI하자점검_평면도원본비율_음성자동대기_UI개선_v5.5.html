평면도 원본비율·음성 자동대기 UI 개선

상세 평면도의 왜곡을 제거하고 하자의견 입력을 음성 중심의 단일 인터페이스로 단순화했다.

적용 내용

구분구현 결과
평면도 상세보기원본 이미지의 가로·세로 비율을 계산해 화면 안에 맞춤 표시한다. 빈 여백은 허용하되 이미지를 늘이거나 자르지 않는다.
확대·축소1~5배 핀치 줌, 드래그 이동, 더블탭 1배 초기화를 유지한다. 하자 핀과 라벨도 이미지와 같은 좌표계로 확대된다.
하자의견 진입페이지 진입 약 0.35초 후 입력창에 포커스를 주고 앱 음성인식을 자동 시작한다. 권한이 없으면 Android 마이크 권한 요청을 표시한다.
마이크 상태음성인식 중에는 제목 오른쪽의 빨간 마이크 아이콘이 약 0.45초 간격으로 점멸한다. 대기 상태에서는 회색으로 표시하며 누르면 다시 시작할 수 있다.
화면 단순화제목 오른쪽의 ‘음성인식/문자’ 선택 버튼은 삭제했다. 하나의 하자의견 입력창에서 음성 결과와 직접 문자를 모두 받는다.
