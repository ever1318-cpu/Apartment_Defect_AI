1. 이번 수정의 결론

하자DB는 더 이상 임시 동·호 목록을 보여주지 않는다. 서버 DB에서 전송 및 마감이 완료된 세대만 동·호 풀다운에 나타난다. 또한 기본 점검자 ID를 Master로 통일하고, 라이브 디텍션의 사진 구성 선택은 촬영 화면이 아닌 촬영 설정 안으로 이동했다.

2. UI/UX 수정 목록

영역변경 내용상태
라이브 디텍션본문 상단에 있던 근경 1장 / 근경 + 원경 선택 버튼을 제거했다. 우측 상단 톱니바퀴의 촬영 설정 → 하자 촬영 방식에서만 변경한다. 기본값은 근경 1장이다.APK 반영

하자DB 풀다운101~120동과 기본 호수의 임시 선택지를 삭제했다. API가 반환한 실제 세대만 동 목록에, 선택 동에 속한 실제 세대만 호 목록에 표시한다.앱·서버 반영
조회 기준PostgreSQL 갤러리 조회는 inspection_sessions.state = 'COMPLETED' 조건을 적용한다. 점검 중, 전송 중, 미마감 세대는 하자DB 조회 대상이 아니다.서버 코드 반영
빈 데이터 안내통신이 정상인데 조회 세대가 없으면 “서버 통신은 정상입니다. 전송 및 마감이 완료된 세대 점검 데이터가 아직 없습니다.”를 표시한다. 특정 세대를 정상 조회했으나 자료가 없을 때도 별도 안내를 표시한다.APK 반영

3. 하자DB 표시 규칙

서버 DB inspection_sessions.state = COMPLETED │ ├─ 삭제되지 않은 하자(defects) 존재 │ │ │ ▼ │ GET /v2/field/gallery/households │ │ │ ▼ │ 하자DB: 동 목록 → 해당 동의 호 목록 → 사진·메타데이터 │ └─ 미마감 / 점검중 / 전송중 └─ 하자DB 풀다운에 표시하지 않음

정상·데이터 있음

마감 완료 세대가 풀다운에 표시되고, 선택 시 하자 이미지·분류·의견·메타데이터를 갤러리로 보여준다.

정상·데이터 없음

서버 연결은 유지하되 마감 완료 세대가 없다는 안내를 표시한다. 네트워크 오류로 잘못 안내하지 않는다.

통신·서버 오류

VPN/주소 오류, 권한 오류, 404 구버전 API, 5xx 서버 오류를 각각 별도 메시지로 구분한다.

5. 적용을 위한 서버 재시작

이번 변경에는 PostgreSQL 갤러리 조회 SQL 조건이 포함되어 있다. 현재 실행 중인 Field API가 이전 프로세스라면 코드 변경이 즉시 반영되지 않으므로, 다음 순서로 한 번 재시작한다.

  1. 기존 Field API PowerShell 창에서 Ctrl+C로 종료한다.
  2. D:\AI_projects\Apartment_Defect_AI에서 다음을 실행한다.

.\scripts\run_field_postgres_server.ps1 -Port 8001

재시작 후 PC에서 Invoke-RestMethod http://127.0.0.1:8001/v2/field/gallery/households로 목록을 확인하고, 휴대폰 하자DB를 다시 열어 확인한다.

6. 현장 확인 절차

  1. 휴대폰 앱에서 한 세대의 하자를 저장하고 전송 및 마감까지 완료한다.
  2. 하자DB를 열고 해당 동·호가 풀다운에 나타나는지 확인한다.
  3. 동·호를 선택해 사진, 가상 참고 이미지 표기, 분류·의견 메타데이터를 확인한다.
  4. 마감하지 않은 다른 세대가 하자DB 풀다운에 나타나지 않는지 확인한다.
