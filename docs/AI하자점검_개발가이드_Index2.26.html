D-90 ~ D-45 아파트 품질·하자점검 AI 도입 통합개선 설계서

v1.0 · 2026-08-03 · 전문가 품질점검, 보수관리, 입주자 사전점검을 하나의 하자 데이터 흐름으로 연결

설계 결론
가장 효과적인 AI 도입은 “사진을 보고 AI가 하자를 자동 확정”하는 방식이 아닙니다. 사진·세대/공용부 위치·점검자 의견·표준 5계층 코드·보수 상태를 한 건의 하자 ID로 묶고, AI가 누락·중복·오분류를 줄이며 점검자의 확정을 빠르게 하는 Human-in-the-loop 품질관리 시스템으로 설계해야 합니다.

2. 입력 화면: “한 번 찍고, 한 번 확인”

현장 입력은 스크롤과 타이핑을 최소화해야 합니다. 한 화면에서 아래 순서로 진행합니다.

  1. 자동 맥락 불러오기: 로그인 권한, 단지·동·호 또는 공용부, 평면도, 현재 앵커·동선을 자동 표시
  2. 사진 확보: 기본은 근경 + 원경, 필요 시 설명 스티커/메모 사진. 촬영 실패·흐림·중복을 즉시 경고
  3. 하자 설명: 음성 또는 짧은 문자로 자유 입력. 원문은 절대 수정·삭제하지 않고 보존
  4. AI 후보: 위치.부위.상세부위.공종.원인 Top-3와 유사 전문가 사례를 표시
  5. 점검자 확정: 후보 채택·수정·“잘 모르겠음” 중 하나만 선택해 저장
AI가 확신하더라도 초기 운영에서는 자동 저장하지 않습니다. 전문가 품질점검에서는 점검자 확정을 필수로 하고, 입주자 입력은 AI 제안과 원문을 분리 저장합니다.

4. AI를 투입할 지점과 기대효과

사진 품질 게이트흐림·너무 어두움·렌즈 가림·중복·무관 사진을 즉시 재촬영 요청
중복·재발 탐지같은 세대·공간의 과거 하자와 사진/문장 유사도를 비교
5계층 후보 추천전문가 Gold 사례를 근거로 후보 3개를 제안하고 확정 시간 단축
의견 표준화입주자·STT 원문을 보존한 채 보수지시용 표준 문장으로 병기
보수 검증 보조보수 전후 사진 연결, 미완료·사진 누락·동일 증상 재발 후보 표시
관리자 관제공종·동·공간별 집중 하자와 마감 위험 세대를 우선순위화

5. 시스템 오류를 줄이는 핵심 장치

위험권장 통제
통신 끊김·VPN 불안정Local-first: 사진과 메타데이터를 기기 DB/암호화 파일에 먼저 원자적으로 저장. 업로드는 재시도 큐·이어올리기·해시 검증으로 수행.
근경/원경 한 장 누락각 사진을 개별 슬롯·상태로 관리. 전송 전 “근경/원경/메모” 완결성 검사, 누락은 재촬영 또는 명시적 예외사유.
같은 하자 중복 등록동·호·공간·좌표·시간·이미지 해시·텍스트 임베딩으로 유사도 후보를 제시하되, 병합은 관리자 승인.
잘못된 위치평면도 자동 핀을 기본값으로 쓰고 수동 이동은 확인창·수정 이력·변경자 기록을 남김.
AI 오분류Top-3 + 신뢰도 + “잘 모르겠음” 제공. 낮은 신뢰도 자동확정 금지. 점검자 수정값만 Gold 후보로 반영.
보수 완료 오판보수 전/후 사진·조치자·조치일·재점검자 확인을 분리. AI는 보조 경고만 수행.

8. 단계별 도입 로드맵

  1. 1차: 데이터 완결성 — 현재 앱에 Local-first 저장, 근경·원경 슬롯, 5계층 확정, 보수 전후 이력, 전송 모니터를 완성
  2. 2차: 전문가 AI 보조 — Gold 데이터로 사진 품질·중복·5계층 후보 모델을 운영, 자동확정은 하지 않음
  3. 3차: 보수관리 연동 — 협력업체 배정·기한·조치증빙·재점검을 하자 ID로 연결
  4. 4차: 입주자 사전점검 확대 — 입주자 원문을 표준화하고 기존 전문가 하자와 중복/재발 여부를 안내
  5. 5차: 모델 고도화 — 현장 수정·최종확정 사례만 재학습에 편입, 단지 외부 검증 통과 모델만 배포

최우선 실행 항목

  1. 전문가 품질점검 Gold 후보의 입력자·승인상태·사진/5계층 완결률을 RDS read-only로 확정
  2. 하자 ID 중심의 사진·위치·원문·AI제안·최종확정·보수이력 데이터 계약 확정
  3. 근경·원경·스티커 사진의 저장/재시도/해시검증을 실기기에서 검증
  4. 전문가 검수형 AI Top-3 추천 Pilot을 한 단지에서 먼저 운영

핵심은 하자를 더 많이 입력하게 만드는 것이 아니라, 보수업체가 바로 실행할 수 있는 완결된 하자 패키지를 빠르고 신뢰성 있게 생산하는 것입니다.
