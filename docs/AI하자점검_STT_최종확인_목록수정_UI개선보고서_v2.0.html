1. 구현 결과

영역적용 내용
STT 의견 입력‘STT 음성으로 의견 추가’ 메뉴와 마이크 아이콘, 한국어 음성인식 안내문구 제공
원문 보존음성인식 결과를 기존 입주민 의견 뒤에 추가해 RAW 의견 흐름 유지
입력 대체STT 취소·미지원 시 안내 후 키보드 입력을 그대로 사용
하자 상세정보‘최종확인 입력/내용 수정’ 버튼 추가, 저장 시 완료 상태 전환
사진 메뉴‘추가 촬영’을 ‘수정/추가 사진’으로 변경
수직 길이카드 패딩, 중간 간격, 의견·AI 입력 높이를 축소
최종 목록각 하자 카드를 누르면 상세정보 화면으로 이동해 확인·수정 가능
