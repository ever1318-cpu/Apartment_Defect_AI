확인 결과

서버 하자DB에는 공용부·기타 2건과 근경 사진 메타데이터가 저장되어 있습니다. 사진이 앱에서 보이지 않은 원인은 DB 객체키의 구분기호와 실제 서버 파일명의 정규화 규칙이 달라 콘텐츠 조회가 404가 된 것입니다.

반영 사항

구분변경
공용부 정렬하자DB 동 선택 목록에서 공용부·기타를 항상 마지막에 표시
공용부 기록공용부 하자 카드를 공용부 기록 1, 기록 2 형식으로 표시
사진 열람기존 파일명 불일치 기록은 로컬 사진번호(Pxxxxx)로 안전하게 복구 조회. 새 저장 건은 서버와 동일한 정규화 파일명으로 DB에 등록
공용부 촬영공용부·기타 진입 시 기본 촬영을 근경 + 원경으로 설정. 카메라 설정에서 변경 가능
공용부 위치풀다운 제공: 공용부 추가, 지하주차장, 공동현관, 복도·계단, 승강기홀, 옥상·외벽, 보도·조경 등
설정 정리인트로의 점검현황·서버/VPN 설정·최초 앵커 촬영 메뉴를 우측 상단 설정 아이콘으로 이동

적용 및 검증

백엔드 테스트 16건 통과, Android Debug APK 빌드 성공. 서버 변경을 적용하려면 Field API를 한 번 재시작해야 합니다.

cd D:\AI_projects\Apartment_Defect_AI
.\scripts\run_field_postgres_server.ps1 -Port 8001

재시작 후 하자DB에서 공용부·기타를 선택하면 기존 사진도 열람 가능합니다. 새 APK 설치 후 촬영한 사진은 파일명도 즉시 일치합니다.
