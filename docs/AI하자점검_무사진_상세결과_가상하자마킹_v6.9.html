무사진 하자 상세결과 가상 마킹

사진 없이 입력한 하자도 저장 후 결과 화면에서 가상 상태를 명확히 확인할 수 있도록 보완했다.

적용 내용

  • 상단 단계 바에서 사진 없이 하자의견 단계로 이동 가능
  • 사진 없는 입력을 평면도 중앙 기본 위치의 가상 하자로 저장
  • 입력 화면에 가상 하자 / 사진 없음 표시
  • 저장 후 상세정보 상단에도 동일한 가상 하자 표시
  • 실제 사진이 없는 상태를 사진 데이터와 혼동하지 않도록 명시
