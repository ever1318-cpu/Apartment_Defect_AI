인트로 최초공간 앵커·현재 동 표시 개선

북향 오인 방지, 최초 촬영공간 기준 위치 추적 및 단지 내 현재 동 강조

Android UI v1.62026-07-24

1. 변경된 시작 흐름

세대 조회 → 단지 내 현재 동 확인 → 평형 확인 → 최초 사진 공간 선택 → 공간 좌표를 세션 앵커로 저장 → 촬영·후속 위치 표시

2. 구현 내용

항목구현상태
방위 표시세대 평면도의 N 표식을 삭제했다. 설계도 이미지가 정북 기준이라는 잘못된 인상을 주지 않는다.완료
인트로 안내문‘테스트 기본 ID 점검매니저…’를 포함한 상단 안내 블록 전체를 삭제했다.완료
최초 공간자동 선택을 없애고 사용자가 ‘1. 최초 사진 위치(앵커) 선택’에서 직접 공간을 선택하도록 변경했다.완료
세션 앵커선택 공간의 정규화 좌표와 공간명을 Session.startXNorm/startYNorm/anchorLocationLabel에 카메라 실행 전 저장한다.완료
평면도 표시선택 공간 좌표에 빨간 앵커를 즉시 표시하며 후속 위치 확인 화면에서도 기준점과 현재 위치 연결에 사용한다.완료
현재 동세대 동 번호를 추출해 101~120동 좌표표와 대조하고 단지안내도 위에 빨간 현재 동 마커를 표시한다.완료
스크롤 축소안내 블록 제거, 단지안내도 높이 176dp, 최초 공간 칩을 단일 가로 목록으로 구성했다.완료
이미지 재사용세션의 평면도 ID가 단지안내도 자산을 계속 참조하므로 이후 상세·보고 화면에서 동일 이미지를 재표시할 수 있다.저장 연결

3. 데이터 원칙

  • 평면도에는 절대 방위를 임의로 부여하지 않는다.
  • 최초 선택 공간은 측위 기준점이며 이후 촬영 위치와 구분해 저장한다.
  • 현재 동 마커는 세대 DB의 동 번호 기반이며 향후 GPS·GIS 좌표가 제공되면 좌표표를 서버 데이터로 대체한다.
  • 단지안내도와 평면도 원본은 변경하지 않고 UI 오버레이만 표시한다.
