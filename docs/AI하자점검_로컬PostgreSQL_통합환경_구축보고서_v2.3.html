2. 구현 산출물

  • 로컬 전용 환경변수: LOCAL_APARTMENT_DB_*
  • localhost 외 주소 차단 setup 스크립트
  • 핵심 스키마 마이그레이션 자동 적용
  • 울산다운 101~120동·1~25층·1~4라인, 총 2,000세대 seed
  • 84A-1·84B-1 평면도와 공간 앵커 메타데이터
  • PostgreSQL 기반 FastAPI 실행 팩토리와 서버 스크립트

3. 보안 원칙

운영 APARTMENT_DB_*와 로컬 LOCAL_APARTMENT_DB_*를 분리했다. setup 스크립트는 host가 localhost가 아니면 중단하며, 비밀번호를 파일·로그·보고서에 저장하지 않는다.

4. 실제 적용 명령

cd D:\AI_projects\Apartment_Defect_AI
$env:LOCAL_APARTMENT_DB_PASSWORD = Read-Host "Local PostgreSQL password" -MaskInput
.\scripts\setup_local_field_db.ps1
.\scripts\run_field_postgres_server.ps1

PowerShell 5에서 -MaskInput이 지원되지 않으면 다음을 사용한다.

$secure = Read-Host "Local PostgreSQL password" -AsSecureString
$env:LOCAL_APARTMENT_DB_PASSWORD = [Net.NetworkCredential]::new("", $secure).Password
