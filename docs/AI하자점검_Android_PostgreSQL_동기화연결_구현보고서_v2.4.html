Android·PostgreSQL 동기화 연결 구현

AI하자점검 개발가이드 · Integration v2.4 · 2026-07-24

1. 구현 결과

Android의 기존 로컬 우선 저장·재시도 구조를 유지하면서 새 /v2/field PostgreSQL API 계약으로 전환했다. Room 파괴 마이그레이션 없이 기존 sync_queue.entityId를 하자 client UUID로 활용한다.

2. 단말 동기화 순서

순서동작
1동·호수로 /households/resolve 호출
2로컬 세션 ID·세대명으로 안정적인 session client UUID 생성
3서버 점검 세션 생성 또는 기존 세션 재사용
4인트로 공간 좌표·앵커 위치·방위 동기화
5근접·광각 이미지 업로드
6하자 client UUID, RAW/STT 의견, 최종 분류를 field batch로 전송
7서버 revision 저장, 충돌 또는 재시도 상태를 로컬 큐에 기록

3. 보안·환경

  • Debug 빌드만 사설 LAN HTTP 허용
  • Release 빌드는 계속 HTTPS 강제
  • 현재 개발 PC 주소: 192.168.0.205:8000
  • 운영 RDS 직접 연결 없음 — Android는 FastAPI만 호출

4. 검증

동기화 단위 테스트와 LAN API URL이 주입된 debug APK 패키징을 통과했다.
