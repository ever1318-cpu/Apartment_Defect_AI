Apartment Defect AI · Android STT

STT 3초 자동마감·줄 누적 v4.9

구현 결과

한 번의 음성 발화를 한 줄로 기록하고 마지막 인식 이후 3초 대기 시 자동 마감하도록 구현했다.

음성 입력 → 부분 문장 실시간 표시 → 3초 무입력 → 자동 마감 → 다음 음성을 새 줄에 누적

동작 원칙

  • 새 음성 입력은 기존 문장을 덮어쓰지 않는다.
  • 각 발화는 줄바꿈 문자로 구분해 저장한다.
  • 수동 STT 마감도 동일한 누적 규칙을 사용한다.
