1. 최종 UX 원칙

  • 최소 입력: 동·호수와 최초 공간을 선택하면 도면과 세대 컨텍스트를 자동 적용한다.
  • 사진 중심: 하자 등록은 라이브 카메라 촬영에서 시작하며 사진 없는 신규 하자 입력을 기본 흐름으로 두지 않는다.
  • 용어 단순화: “앵커 위치·촬영기준” 대신 “앵커”, 저장 동작은 “최종확인 & 저장”으로 통일한다.
  • 원문 보존: 점검자·입주자 의견 RAW와 STT 기록을 AI 표준문구가 덮어쓰지 않는다.
  • 추천과 확정 분리: 이미지 AI, 텍스트 AI, 점검자 의견을 합치되 최종분류는 사람이 수정·확정한다.
  • 세대 격리: 세대 마감 후 다음 호수는 새 세션으로 시작하며 이전 핀·집계·앵커를 표시하지 않는다.

3.5 점검자 의견·STT·AI 어시스턴트 구현

  • 점검자 의견과 AI 분석 의견을 별도 박스로 구분하고 여백을 축소했다.
  • 앱 내부 SpeechRecognizer가 말하는 중 부분문장을 별도 기록창에 실시간 표시한 뒤 점검자 의견에 반영한다.
  • 최초 사용 시 마이크 권한을 요청하며, 동일 버튼으로 인식을 중지하고 권한·네트워크·무음·인식 실패 상태를 안내한다.
  • 점검자 의견 → AI 분석과 AI 분석 의견 → 점검자 의견 양방향 변환을 제공한다.
  • 점검자·입주자 RAW 의견은 최종분류 문구와 별도로 끝까지 저장한다.
  • AI·이미지 추천의 화살표와 “확인필요”를 제거하고 거실, 벽, 도장, 균열처럼 쉼표 목록으로 표현한다.
  • 섹션 제목은 촬영 이미지 AI분석 추천으로 표시하고 불필요한 하단 설명을 삭제했다.
  • 최종분류는 입주자 의견, AI 추천, 이미지 추천, 점검자 추가 의견을 통합한 뒤 점검자가 편집한다.
  • 최종 동작 문구는 최종확인 & 저장으로 통일했다.

8. UI/UX v3.1 추가 구현

촬영·판별

  • 판별확인 문구를 사진앵커 : 남동향 SE120도 / 0.5m 형식으로 단순화했다.
  • 촬영 이미지 오른쪽의 큰 나침반을 제거하고 이미지 높이를 280dp로 확대했다.
  • 하자사진 촬영 시 Android 표준 셔터음을 재생한다.

의견·단계 안내

  • Phase 3 Real API 의견입력란에 한국어 실시간 STT를 직접 연결했다.
  • 상단에 앵커 → 하자사진 → 하자의견 → AI분류 단계 표시를 추가했다.
  • 카메라, 위치확인, 의견 상세, AI분류 화면에서 현재 단계를 강조한다.

인트로·세대 추천

  • ‘자동조회’ 표시는 제거하고 DB 조회 또는 기본값에서 결정된 평형을 표시한다.
  • 사용자 표시는 아이디: 점검매니저 / 소유주 선택형이며 기본값은 점검매니저다.
  • ‘동·호수 자동 부르기’는 GPS 위치 신호와 직전 점검 호수의 순서를 결합해 인접 세대를 추천하며, 점검자가 적용을 눌러 확정한다.
  • 실내 GPS가 약한 경우에는 같은 동의 다음 라인 또는 다음 층 1호를 추천한다.

위치 추천 안전 원칙

GPS만으로 아파트 호수를 확정할 수 없으므로 자동 저장하지 않는다. 향후 단지·동 좌표와 점검 배정표 DB가 제공되면 GPS는 동 후보를 좁히고, 점검 순서 데이터가 호수를 추천하도록 확장한다.

9. UI/UX v3.2 위치확인·인트로 개선

인트로 세대 카드

  • 상단 아이디 선택과 중복되던 세대 카드의 ‘점검매니저’를 삭제했다.
  • 평형은 (평형:84A-1) 형식으로 표시한다.
  • 단지·동호수와 평형 블록은 두 줄을 넘지 않도록 제한한다.

현재 단계 표시

  • 앵커·하자사진·하자의견·AI분류 중 현재 단계가 0.55~1.0 투명도로 점멸한다.
  • 위치확인 상단 센서 정보는 강한 강조색 대신 채도를 낮춘 청회색을 사용한다.

핀 위치 안전 보정

  • 최초 하자 핀은 센서·이미지 분석의 자동 추정 위치로 고정한다.
  • 평면도를 누르면 즉시 이동하지 않고 위치 수정? 확인창을 표시한다.
  • 점검자가 ‘위치 수정’을 선택한 경우에만 핀을 수동 위치로 변경한다.

방향·나침반

  • 방향은 동향 E109도처럼 한글 방위, 영문 방위, 각도 순으로 표시한다.
  • 위치확인 평면도 오른쪽 위에 촬영 방향을 반영한 소형 나침반을 표시한다.

  • 앵커 설정 후 접수현황에서는 별도 앵커 배너를 제거해 세로 공간을 확보한다.
  • 이후 단계 메뉴는 하자사진 → 하자의견 → AI분류 3단계만 표시한다.

평면도 닻 마커

  • 접수현황 미니 평면도, 전체 평면도, 촬영 미니맵, 위치확인 평면도에 동일한 닻 형태를 사용한다.
  • 닻은 최초 앵커 좌표에 고정되며 청록색으로 표시해 빨간 하자 핀과 구분한다.
  • 이동 경로 표시를 끈 전체 평면도에서도 닻 마커는 계속 표시한다.
