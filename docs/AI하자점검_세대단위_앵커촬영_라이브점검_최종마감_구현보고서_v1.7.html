세대단위 앵커촬영·라이브점검·최종마감 구현

동·호수 선택부터 최초 위치 앵커, 하자 반복 촬영, 집계·누적핀 확인 및 세대 마감까지

Android v1.72026-07-24Galaxy S25 Ultra 검증

1. 업무 흐름

동·호수 선택 → 최근값 저장 → 최초 공간 선택 → 앵커 사진 촬영 → 홈 → LIVE DETECTION 하자 반복 입력 → 전체 목록·집계·누적핀 확인 → 세대 점검 최종 마감 → 다음 호수

2. 구현 사항

영역적용 내용상태
인트로 입력점검 ID 자유입력을 동 번호·호수 선택으로 분리하고 세대소유주는 ‘점검매니저’로 고정 표시완료
최근 세대값last_household 환경에 마지막 동·호수를 저장해 다음 호수 점검 시 초기값으로 복원완료
공간 선택거실·안방·주방 등 공간 칩을 화면 폭 안에서 정확히 두 줄로 배치완료
앵커 확정공간 좌표 선택 후 반드시 ‘최초 위치 앵커 촬영’을 수행하며, 앵커 사진 저장 전에는 일반 촬영을 활성화하지 않음완료
후속 하자 입력앵커 완료 후 홈의 새 하자 입력은 모두 LIVE DETECTION · 하자 촬영으로 이동완료
상세 버튼‘수정 / 추가 촬영 / 삭제’의 간격·가중치·내부 여백을 조정해 문구 잘림 제거완료
마감 보고기존 전체 목록, 심각도·공종·공간 집계에 최종 평면도와 누적 하자 핀을 추가완료
최종 마감전체·미확인·완료 건수를 확인하는 다이얼로그 후 Session.done=true로 저장하고 다음 세대 인트로로 이동완료

3. 안전장치

  • 공간 목록이 로딩 전 비어 있어도 두 줄 분할 크기를 최소 1로 보정하여 충돌하지 않는다.
  • 평면도 좌표 선택만으로 앵커 완료 처리하지 않고 실제 앵커 사진 존재 여부를 함께 검사한다.
  • 최종 마감 전 전체 하자 목록과 평면도 누적 핀을 동시에 확인한다.
  • 동·호수 입력은 숫자만 저장하며 화면 폭 때문에 마지막 숫자가 가려지지 않도록 두 칸으로 분리했다.
