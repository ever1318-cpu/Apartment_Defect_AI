1. 검토 결론

현장 흐름 자체는 완결되어 있다. 가장 큰 개선 기회는 AI 추천 정보의 표기 일관성과, DEMO 모드 진입이 화면에 드러나지 않는 문제다.

핵심 발견

동일한 AI 추천이 화면마다 나열형/계층형, 서로 다른 신뢰도 숫자로 표기됨

가장 시급한 위험

인증 실패 시 DEMO 모드 무저장 상태가 세대 마감까지 화면에 드러나지 않음

문서 성격

v4.4 실기기 캡처 기반 역설계 제안 — 목업이 아닌 실제 화면 근거

2. AI 추천 표기 일관성 (핵심 발견)

동일한 "AI가 추천한 값"이 점검 흐름의 세 지점에서 서로 다르게 표기된다. 점검자가 무엇에 대한 몇 %인지 헷갈릴 수 있고, 결국 최종 확정 라벨의 정확도 — 즉 다음 모델 재학습 데이터의 품질 — 에 영향을 준다.

화면표기 방식신뢰도문제
11-pin-review단일 지명 + 화살표75%이게 "위치" 신뢰도라는 라벨이 없음
12/13-opinion쉼표 나열 (거실, 천장, 마감)55%계층 관계가 안 보임, 신뢰도 대상 불명확
15-detail-top계층형 (거실 > 천장 > 마감)표기 없음"확인 필요" 플래그가 왜 붙었는지(임계값) 기준 불명확

제안

  • 신뢰도 숫자는 항상 대상을 함께 명시: "위치 추정 75%" / "하자유형 추천 55%"
  • 후보 표기는 계층형(>)으로 전 화면 통일 — 나열형(쉼표) 제거
  • "확인 필요" 플래그는 신뢰도 임계값(예: 60% 미만) 기준으로 시스템이 자동 부착 — 지금은 왜 붙었는지 규칙이 화면에 없음

4. 역설계 제안 — 의견·AI 분류 화면

Before

  • 1 점검자의견·AI분석 → 2 이미지AI추천 → 3 최종분류 → 4 현장메모, 4단계 모두 항상 펼쳐짐
  • 완료한 단계도 계속 화면을 차지해 스크롤이 길어짐
  • AI 추천 신뢰도(55%)와 후보 목록이 나열형으로만 표기

After (제안)

  • 완료된 단계는 한 줄 요약 + "수정" 링크로 접힘 (아코디언), 현재 진행 단계만 펼침
  • 단계 진입 시 이전 단계 요약이 상단에 고정 노출되어 맥락 유지
  • AI 추천은 "하자유형 추천 55% · 거실 > 천장 > 마감" 계층형 한 줄로 통일 표기 (2번 섹션 기준 적용)
  • 최종 확정 문장은 3개 이상 후보 태그가 있어도 항상 완결된 문장으로 생성되도록 템플릿 점검 (현재 "AI 이미지 분석 후보: 거실, 천장," 에서 문장이 끊겨 보이는 현상 확인 필요)

5. 역설계 제안 — 점검 홈

Before

  • 완료율 0%인데도 "마감" 버튼이 "새 하자 입력"보다 상단에 위치
  • "새 하자 입력" 카드 하단 텍스트가 다음 섹션에 잘려 보임

After (제안)

  • 완료율에 따라 두 CTA의 시각적 우선순위를 동적으로 전환: 진행 중(완료율<100%)엔 "새 하자 입력"을 최상단 주 CTA로, 마감 버튼은 보조 위치로 이동
  • 모든 항목이 완료(또는 사용자가 목록을 확인)된 뒤에만 마감 버튼이 주 CTA 색상으로 강조되도록 상태 기반 스타일링

6. 역설계 제안 — 로그인 실패 · DEMO 모드

Before

  • 인증 실패 → 안내 문구 없이 DEMO 모드로 조용히 진행
  • 홈(14)·상세(15)·평면도(18)·목록(19)·리포트(20/21) 어디에도 DEMO 표시 없음
  • 세대 마감 시점에야 무저장 상태를 알게 될 위험

After (제안)

  • 인증 실패는 즉시 재시도를 유도하는 명확한 오류로 우선 처리 (DEMO 자동 전환보다 재입력 유도가 먼저)
  • 그럼에도 DEMO로 진입했다면 헤더 배경색을 경고색으로 바꾸고 "DEMO 모드 · 저장 안 됨" 텍스트를 모든 화면 상단에 고정
  • 마감 시도 시 DEMO 상태라면 마감을 막고 재로그인을 요구하는 확인 다이얼로그 추가
