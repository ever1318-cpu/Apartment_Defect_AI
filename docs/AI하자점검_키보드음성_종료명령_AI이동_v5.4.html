키보드 음성입력·종료명령·AI 단계 이동

하자의견 입력을 하나의 입력창으로 단순화하고, 음성/문자 입력부터 AI 분석과 종합의견 확정까지 연속 흐름으로 구성했다.

항목적용 내용
입력 선택1. 하자의견 옆에 음성인식 / 문자 버튼 배치. 초기값은 음성인식 강조 상태다.
키보드 음성음성인식을 누르면 의견 입력창에 초점을 주고 스마트폰 키보드를 표시한다. 사용자는 키보드 왼쪽 아래 마이크를 눌러 말하며, 변환 문자는 동일 입력창에 기록된다.
문자 입력문자를 선택하면 같은 입력창에 일반 키보드 입력을 이어서 기록한다.
종료 명령끝, 마감, 엔터, 종료, 엔드가 문장 끝에 입력되면 종료어를 본문에서 제거하고 의견 입력을 마감한다.
단계 이동입력 마감 후 AI 분석/분류를 실행하고 해당 영역으로 이동한다. 분석 완료 뒤 종합의견 영역을 강조하여 최종 저장을 유도한다.
오입력 방지마감재 균열처럼 종료어가 다른 단어의 일부인 경우에는 마감하지 않는다.
