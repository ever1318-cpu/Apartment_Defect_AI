세대순환: 저장·집계·마감·다음 호수

AI하자점검 개발가이드 · 구현 v2.1 · 2026-07-24

1. 운영 흐름

상세부위 확정 저장 → 세대 현황·집계 → 추가 하자 입력 또는 목록 수정 → 세대 점검 마감 → 다음 호수 인트로

2. 구현 결과

단계적용 내용
하자 저장상세부위 확정 후 개별 상세 화면 대신 세대 현황 홈으로 복귀
현황 확인전체·미확인·완료 집계와 최근 하자 목록을 즉시 확인
추가 입력같은 화면에서 라이브 디텍션을 다시 실행해 하자를 연속 등록
마감 진입‘통계·목록 확인 후 세대 점검 마감’ 버튼 추가
최종 검토최종 평면도·누적 핀·전체 목록을 확인하고 항목별 상세 수정 가능
다음 호수마감 후 1501→1502→1503→1504→1601 방식으로 다음 호수를 인트로 기본값에 설정

3. 안전 조건

등록 하자가 없으면 마감 버튼을 비활성화한다. 이미 마감된 세대는 재마감할 수 없다. 동·호수 형식을 해석할 수 없으면 다음 호수를 임의 계산하지 않고 기존 직접입력 흐름을 유지한다.
