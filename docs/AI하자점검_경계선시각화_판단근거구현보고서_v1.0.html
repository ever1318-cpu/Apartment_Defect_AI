AI하자점검 경계선 시각화 판단근거 구현보고서 v1.0

적용 일자: 2026-08-03 / 대상: 하자사진 미리보기 및 사진 확대 뷰

구현 결과

  • IMU+이미지 율합으로 천장-벽 또는 벽-바닥 접합부가 검출되면 사진의 실제 Y 위치를 정규화해 저장한다.
  • 하자의견 입력화면의 근경·원경 미니사진에 황색 경계선을 노출한다.
  • 사진을 눌러 열리는 3장 캐러셀 확대뷰에서도 동일한 라인과 ‘천장-벽 경계’ 라벨을 표시한다.

황색 라인 = AI가 판단 근거로 사용한 수평 접합선

표시 원칙

상태사진 표시상세부위 제목
천장-벽 추정상단에 검출된 수평선거실/천장-벽
벽-바닥 추정하단에 검출된 수평선거실/벽-바닥
평면 부위경계 없음; IMU 기울기 기준거실/천장, 거실/벽, 거실/바닥

데이터 보호

경계선은 UI 오버레이이며 원본 사진 파일을 변경하지 않는다. 따라서 증거사진의 원본성과 전송 무결성을 유지한다.

검증

Android Debug APK 빌드 성공. 현장에서는 천장-벽, 벽-바닥 사진을 표본 촬영하여 라인이 접합부와 일치하는지 확인한다.
