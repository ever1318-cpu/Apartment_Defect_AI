AI하자점검 분류마스터 DB·API 설계서 v1.0

2026-08-03 · 평면도·실·부위·상세부위·A/S 원인·공종을 단일 기준으로 관리

설계 결론
현재 화면별로 흩어진 선택 메뉴를 평형 → 실 → 5각도 부위 → 상세부위 → 원인 → 공종의 마스터 관계로 전환합니다. 앱은 서버가 연결될 때 조회하고, 현장 통신이 끊기면 마지막 동기화본을 로컬 캐시에서 사용합니다.

1. 현 화면의 문제와 개선 원칙

현재개선
평면도, 실, 부위, 상세부위, 원인이 각각 화면 코드 또는 고정 목록으로 존재PostgreSQL 마스터에서 하나의 선택 체계를 조회
평형·공용부·세대별 조합에 맞는 메뉴 관리가 어려움평형/실/부위 조건으로 후보를 필터링하고 상세부위는 최대 5개만 제시
새 마감재·원인을 앱 업데이트 없이 반영하기 어려움서버에서 마스터만 추가·비활성화하고 앱은 다음 동기화 때 반영

2. 표준 분류 흐름

평형84A-1, 84B-1, 공용부
실·공간현관에서 시계방향 순서
부위천장 / 천장-벽 / 벽 / 벽-바닥 / 바닥
상세부위AI 후보 최대 5개 + 직접 입력
A/S 원인시공불량·미시공·파손·누수·결로 등
공종도장·도배·타일·설비·전기 등

예: 84B-1거실벽도배지시공불량도배

3. DB 물리 모델

테이블역할핵심 컬럼
floorplan_room_master평형별 실 위치와 동선 기준floorplan_id, room_code, room_label, x_norm, y_norm, bbox, clockwise_order
defect_taxonomy_master상세부위·원인·공종의 선택 관계floorplan_type_code, room_code, surface_code, detail_code, cause_code, trade_code
floorplans (기존)평형과 평면도·실 앵커 원본type_code, room_anchors
defects (기존)점검자가 확정한 실제 하자final_location_code, final_part_code, final_detail_code, final_cause_code

초기 마이그레이션은 기존 평면도 앵커를 실 마스터로 이관하고, 5각도별 기본 상세부위·원인·공종을 등록합니다. 현장 검토 후 실별 특수 규칙과 동선 순서는 관리자 기준으로 보정합니다.

4. 앱과 서버 API 계약

GET /v2/field/taxonomy?floorplan_type=84A-1
GET /v2/field/taxonomy?floorplan_type=84A-1&room_code=living
GET /v2/field/taxonomy?floorplan_type=84A-1&room_code=living&surface_code=WALL
응답 항목앱 사용처
rooms평면도 분할 보기, 실 메뉴, 현관부터의 시계방향 동선
surfaces카메라 기울기 기반 5각도 자동 추천의 확정·수정 메뉴
details부위 조건에 맞는 상세부위 후보 최대 5개
causes원인 선택 및 자유의견 보완

5. AI 보조와 점검자 역할

자동 추천점검자 확정
평면도 위 현재 위치/하자 위치, 카메라 각도에 따른 5각도 부위, 이미지·설명 기반 상세부위 Top-5실·상세부위·원인·공종을 선택하거나 직접 입력. 원인과 공종은 사진만으로 자동확정하지 않음.
추천은 하자설명 화면에 5개 이하로 표시선택·수정 결과는 defects에 확정값으로 저장되어 재학습 Gold 후보가 됨

6. 적용 및 검증 절차

cd D:\AI_projects\Apartment_Defect_AI
# 로컬 Field PostgreSQL에만 마이그레이션 적용
.\scripts\setup_local_field_db.ps1
.\scripts\run_field_postgres_server.ps1 -Port 8001
Invoke-RestMethod 'http://127.0.0.1:8001/v2/field/taxonomy?floorplan_type=84A-1&room_code=living&surface_code=WALL'
주의: 위 마이그레이션은 로컬 Field PostgreSQL용입니다. 기존 AWS RDS 품질점검 원본 DB에는 적용하지 않습니다. RDS는 read-only 분석·학습 데이터 추출 용도로 분리합니다.
