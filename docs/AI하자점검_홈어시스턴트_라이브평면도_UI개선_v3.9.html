Apartment Defect AI · Android UI 변경 이력

홈 어시스턴트·라이브 평면도 개선

버전 3.9 · 2026-07-25

1. 반영 결과

AI 하자분류 어시스턴트를 새 하자 입력 직후의 최초 안내로 재배치하고 라이브 촬영 화면의 평면도 가독성을 높였다.

2. 홈 화면

세대 현황 → 세대 마감 → 앵커 안내 → 새 하자 입력 → AI 하자분류 어시스턴트(최초 1회) → 최근 하자 목록
  • 어시스턴트 블록을 새 하자 입력 바로 아래로 이동
  • 해당 세대의 첫 하자가 없을 때 최초 진입용으로 표시
  • 어시스턴트 선택 후 같은 세대 화면에서는 숨김

3. 라이브 디텍션

삭제프리뷰 아래 기울기·방향·거리·줌 텍스트 줄
확대라이브 미니 평면도 폭을 화면 50%에서 68%로 확대
유지현재 위치 방사형 표시, 누적 하자 핀, 앵커 위치

4. 검증

.\gradlew.bat -p android :app:testDebugUnitTest :app:assembleDebug --no-daemon
