적용 사항

요청반영
통신 불량 시 저장사진·메타데이터는 전송 전에 스마트폰 내부 파일과 Room 로컬 DB에 저장합니다. VPN 미연결·서버 중단 상태에서는 전송 대기열에 보존하고, 검증된 네트워크가 복구되면 자동 전송합니다.
최초 앵커새 세션에서 앵커 위치가 비어 있으면 기본값을 현관문 앞으로 설정합니다. 사용자가 지정한 기존 앵커는 유지합니다.
하자설명기존 “하자의견(점검자)”를 하자설명으로 변경했습니다.
저장 버튼설명 박스 바로 아래 버튼을 의견입력 완료 및 저장으로 변경하고 실제 로컬 결함 저장 동작에 연결했습니다. 맨 아래에도 확정 및 저장 버튼을 유지하여 같은 저장 동작을 제공합니다.
근경·원경하자설명 우측에 근경과 원경 미니 사진을 동시에 표시합니다. 각 사진을 누르면 확대 화면으로 확인할 수 있습니다.
스티커 사진“하자 메모 사진”을 설명 스티커로 변경했습니다. 촬영된 사진은 미니로 표시되고, 누르면 확대됩니다.

전송 안전성

  1. 현장 입력 → 기기 내부 파일·로컬 DB 저장
  2. 전송 큐 생성
  3. VPN/서버/인터넷 복구 감지 → 자동 재시도
  4. 앱 종료 중 업로드는 다음 실행 시 대기 상태로 복구
  5. 서버 수신은 idempotency key로 중복 등록을 방지
