AI 분류 어시스턴트 UI/UX v2.0 구현명세서

세대 자동조회 인트로와 AI 분류 어시스턴트 UI v0.3을 연결해, 점검 ID 입력부터 공간 선택·촬영·입주자 의견·AI 분석·분류 수정·최종 확정까지 하나의 전체 화면 흐름으로 구현하기 위한 기준 문서입니다.

1. 구현 목표

입력자는 점검 ID 또는 세대소유주 한 항목만 입력하고, 앱이 DB에서 세대와 도면을 준비한 뒤 AI 점검 흐름을 시작합니다.

HouseholdIntroFlow에서 세대·도면·공간을 자동 준비한 뒤 AiAssistantFlow로 전달합니다. 모든 AI 단계에서 Mini-Floorplan, 나침반, 현재 핀과 방위 텍스트가 유지되며 AI 결과는 언제나 “추천”으로 표시합니다.

2. 화면 흐름

⓪ 세대 자동조회→공간 선택→① Live Detection→② 캡처·Top-3→③ 판정 근거↔④ Taxonomy 수정→⑤ 확정

점검 ID·동호수·세대소유주 입력이 멈추면 DB를 자동 조회하고, 도면이 없으면 초기 기본값을 적용합니다. 신뢰도가 낮으면 ②에서 ⑤ 저확신도 화면으로 분기합니다.

3. 구현 대상 전체 화면

⓪ 세대 자동조회 인트로 — 단일 입력창에서 점검 ID·동호수·세대소유주를 인식하고 300ms 후 DB를 자동 조회합니다. 단지 안내도와 세대 평면도를 표시하고 거실·방1·방2·주방·베란다·현관·화장실 중 점검 공간을 선택하면 아래 AI 화면으로 이동합니다. 등록 이미지가 없으면 앱 내장 기본 안내도와 표준 평면도를 사용하며 fallback 상태를 명시합니다.

7. UX·접근성 규칙

  • 입력창은 점검 ID 또는 세대소유주 하나만 제공하고 별도 불러오기 버튼을 두지 않습니다.
  • 소유주 검색 결과는 마스킹하며, 동명이인일 때만 최소 세대 선택을 요청합니다.
  • Orange=사용자 주 행동, Teal=앵커·위치, Purple=AI, P1/P2/P3=위험도 역할을 바꾸지 않습니다.
  • 나침반은 평면도 우측 상단 4dp, 앱 38dp, N은 빨강으로 고정합니다.
  • 주 행동 버튼은 화면당 하나만 강하게 표시하고 보조 행동은 회색 또는 외곽선으로 둡니다.
  • 신뢰도는 색만으로 표현하지 않고 숫자, 막대, 상태 문구를 함께 제공합니다.
  • 터치 영역은 최소 48dp, 본문은 14sp 이상, 정보 라벨은 11sp 미만으로 내리지 않습니다.
  • TalkBack은 “AI 추천”, “사용자 최종 선택”, “북쪽 방향”, “신뢰도”를 구분해 읽습니다.
  • 네트워크·AI 실패 시 촬영 이미지와 의견을 보존하고 직접 분류로 계속 진행할 수 있어야 합니다.

8. 구현 검수 기준

  • □ 단일 입력 후 300ms DB 자동조회
  • □ 세대소유주 검색 결과 마스킹
  • □ 단지·세대 도면 자동 표시와 fallback 구분
  • □ 선택 room context가 촬영 화면으로 전달
  • □ 5개 화면이 전체 화면 내비게이션으로 연결됨
  • □ 모든 화면에서 평면도·나침반 문맥 유지
  • □ Live AI 비활성 시 일반 촬영 가능
  • □ Top-3 선택과 원탭 확정 동작
  • □ 입주자 원문이 접이식 카드에 보존됨
  • □ Grad-CAM 미제공 시 정직한 없음 상태
  • □ Taxonomy 검색·선택·변경 로그 생성
  • □ 저확신도 질문 최대 2회 제한
  • □ 다시 촬영·직접 분류·담당자 검토 제공
  • □ 회전·프로세스 복원 후 상태 유지
  • □ S25 Ultra 큰 글꼴에서 잘림 없음
  • □ 원문·AI 추천·최종값 별도 저장

9. 단계별 구현 범위

1차 · 세대 인트로, 화면 골격과 기존 API 연결

단일 입력 자동조회, 단지·평면도 fallback, 공간 선택, 공통 Scaffold, 평면도·나침반, 캡처 직후 Top-3, Taxonomy 수정, 저확신도 질문과 기존 의견·후보·확정 API를 구현합니다.

2차 · 이미지 설명과 Live Detection

기능 플래그 아래 실시간 검출 오버레이, Grad-CAM, 유사사례를 연결합니다. 데이터가 없으면 비활성 상태를 유지합니다.

3차 · 운영 정책과 최적화

실사용 로그로 신뢰도 기준을 조정하고, 방위 기반 힌트 검증, 배터리·발열·네트워크 최적화, 접근성 E2E를 완료합니다.

구현 승인 기준: 본 문서의 5화면 구조, 접이식 입주자 의견, 초기 신뢰도 분기 80%/60%를 기준안으로 사용합니다.
