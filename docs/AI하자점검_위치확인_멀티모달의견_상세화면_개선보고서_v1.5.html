위치확인·멀티모달 의견·상세화면 개선보고서

현장 스크롤 최소화, 평면도 원본 비율, 이미지·의견 결합 분류 및 RAW 의견 보존

Android UI v1.52026-07-24Galaxy S25 Ultra 검증

1. 적용 흐름

촬영 이미지 → 위치·평면도 확인 → 이미지 AI 추천 → 초기·추가 의견 → LLM 정리 → 위치 ＞ 하자부위 ＞ 상세부위 ＞ 공종 후보 → 로컬 저장 → 하자 상세정보

2. 구현 내용

영역적용 내용상태
촬영사진세 장의 전체 폭 세로 배열을 4:3 가로 썸네일 스트립으로 변경하여 스크롤 축소구현
평면도84A·84B를 포함한 모든 평면도를 원본 bitmap 비율로 렌더링. 인위적 크롭·세로 확대 제거구현
위치 확인평면도 바로 아래에 추천 부위, 이미지 분석 의견, 신뢰도를 배치구현
화면 명칭‘하자 정보·의견 입력’을 ‘하자정보의견 상세’로 변경구현
초기 의견앞 화면의 위치·이미지 AI 추천을 편집 가능한 초기 의견으로 전달구현
의견 분석추가 의견 입력 후 ‘의견 완성·LLM 분석’으로 이미지와 텍스트 결과를 함께 검토연결 유지
RAW 보존입력 원문은 Defect.residentOpinion, AI 의견은 aiPathText, 최종 확정은 finalPathText로 분리 저장구현
분류 순서최종 입력 계약을 ‘위치 ＞ 하자부위 ＞ 상세부위 ＞ 공종 후보’로 변경구현
상세 화면평면도 폭을 68%로 축소하고 사진을 112×84dp로 정리. RAW·AI·최종·현장메모를 한 카드에 표시구현
추가 촬영하자 상세정보의 ‘추가 촬영’에서 카메라로 이동하고 새 사진을 현재 하자 ID에 귀속한 뒤 동기화 대기열을 갱신구현

3. 멀티모달 데이터 원칙

  • 이미지 전용 모델의 결과와 LLM 의견 분석은 별도 출처 및 신뢰도로 유지한다.
  • LLM이 문구를 교정하더라도 입주민이 입력한 원문은 수정하거나 덮어쓰지 않는다.
  • 최종 분류는 두 분석 결과와 현장 점검자의 확정을 결합한 별도 필드로 저장한다.
  • 오프라인에서는 전체 자료를 단말에 먼저 저장하고 연결 회복 후 동일 묶음으로 동기화한다.
