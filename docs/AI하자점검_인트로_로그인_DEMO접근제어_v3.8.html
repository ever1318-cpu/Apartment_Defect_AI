Apartment Defect AI · Android 접근제어 변경 이력

인트로 로그인·DEMO 접근제어

버전 3.8 · 2026-07-25

1. 반영 결과

점검매니저 또는 소유주 칩을 선택하면 아이디·비밀번호 로그인 팝업이 표시된다.

2. 인증 흐름

역할 선택 → 로그인 팝업 → 디버그 테스트 계정·당일 YYYYMMDD 확인 → 인증 또는 DEMO 모드
일치인증 상태 표시 후 정상 점검 흐름 진행
불일치DEMO 안내 표시, 화면·촬영 체험 허용, 서버 저장·전송 차단
미인증공간 앵커 촬영 시작 시 로그인 팝업 재호출

3. 보안 범위

  • 테스트 인증은 DEBUG 빌드에서만 허용
  • 비밀번호는 화면에서 마스킹
  • 당일 비밀번호는 실행 시점에 계산하고 저장하지 않음
  • DEMO 모드에서는 오프라인 동기화 관리자의 서버 업로드를 차단

운영 배포 전에는 서버 기반 계정 인증과 만료 토큰 방식으로 교체해야 한다.

4. 검증

.\gradlew.bat -p android :app:testDebugUnitTest :app:assembleDebug --no-daemon
