AI하자점검 IMU 이미지경계 5부위 융합 구현보고서 v1.0

구현일: 2026-08-03 / 대상: Android 하자사진 찍기 후 자동 부위 추정

구현 내용

셔터 시점 IMU 피치촬영 사진 상단/하단 수평경계율합 신뢰도5부위 후보상세부위 메뉴
  • 카메라 피치로 천장, 천장-벽, 벽, 벽-바닥, 바닥의 1차 후보를 결정한다.
  • 근경 사진을 1/8로 축소한 후, 상단 1/3와 하단 1/3의 수평 경계 에너지를 계산한다.
  • 상단 경계가 뚜렷하면 천장-벽, 하단 경계가 뚜렷하면 벽-바닥을 추천한다.
  • 피치가 큰 천장/바닥 촬영은 IMU를 우선하고, 경계 정보는 신뢰도를 보완한다.

화면 적용

항목적용 방식
상세부위 제목평면도 위치와 율합 부위를 거실/벽, 주방/천장-벽처럼 표시
상세부위 기본값서버 택소노미와 매칭된 최상위 후보를 즉시 선택
신뢰도IMU와 이미지 경계가 일치하면 0.88, 경계가 부위를 보정하면 0.78, IMU만 있으면 0.68 기준

안전 장치

이미지 평면 분석은 현장 조명·재질에 따라 오탐이 가능하므로, 최종 선택은 점검자가 풀다운에서 변경할 수 있다. 수정된 결과는 재학습 Gold 라벨로 활용한다.

검증

Android Debug APK 빌드 성공. 실기기에서 천장, 코너, 벽, 걸레받이, 바닥 각 10장씩으로 오분류률을 확인하여 경계값(현재 0.18)을 보정한다.
