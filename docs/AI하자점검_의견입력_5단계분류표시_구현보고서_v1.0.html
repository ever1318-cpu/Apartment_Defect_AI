AI하자점검 의견입력 5단계 분류표시 구현보고서 v1.0

적용 일자: 2026-08-03 / 대상: 하자의견 입력 화면

적용 설계

위치: 거실   장소: 천장-벽   세부부위: 천장 몰딩
공종: 창호·목공사   원인: 시공 불량
  • 위치, 장소, 세부부위, 공종, 원인을 의견 입력창 위에 명확히 표시한다.
  • 항목명은 붉은색 계열, 추천·결과값은 기본 테마색으로 시각적으로 구분한다.
  • 동일한 5단계 내용을 하자설명 초기 텍스트에도 자동 기입하여 점검자가 바로 수정·확정할 수 있게 한다.

값 생성 기준

단계출처초기 값
위치평면도 실 매칭, AR/PDR, 이미지 매칭예: 거실
장소IMU 기울기 + 이미지 경계 율합예: 천장-벽
세부부위PostgreSQL 택소노미 최상위 후보예: 천장 몰딩
공종택소노미 detail의 trade_label예: 창호·목공사
원인기본 추천 + 점검자 수정예: 시공 불량

점검자 조작

상세부위는 풀다운에서 최대 5개 후보를 선택할 수 있고, 모르면 자유입력으로 보완한다. 의견 입력창에서 내용을 직접 수정하면 원문 데이터로 보존된다.
