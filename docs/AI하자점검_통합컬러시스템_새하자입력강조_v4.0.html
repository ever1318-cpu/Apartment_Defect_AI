2. 전체 페이지 적용

인트로 → 홈 → 평면도 → 위치 확인 → 의견·AI 분류 → 상세·목록·보고서
  • 공통 상단 앱 바를 딥 네이비로 통일
  • 정보 카드·선택 영역은 소프트 블루 계열 사용
  • 앱 배경과 테두리·본문 색상을 저채도 블루그레이로 정리
  • 경고·상태·앵커의 의미 색상은 유지

3. 새 하자 입력 강조

⚡ 새 하자 입력 (사진, 의견)　 주요 작업
  • 76dp 높이, 17sp 굵은 제목
  • 오렌지→딥 오렌지 그라데이션
  • 밝은 테두리와 10dp 그림자
  • ‘주요 작업’ 배지로 행동 우선순위 명시
