1. 현재 확인 결과

서버 상태: 정상. /health 응답은 healthy / postgresql / ready로 확인되었고, 기존 세대 완료 점검 기록은 갤러리 목록에서 조회됩니다.
공용부 DB 대상: 아직 생성되지 않았습니다. GET /v2/field/households/resolve?building_no=COMMON&unit_no=0000 호출 결과가 404 HOUSEHOLD_NOT_FOUND였습니다. 따라서 현재는 공용부 사진·의견이 서버 DB에 저장되거나 하자DB 갤러리에 표시될 수 없습니다.

2. 원인과 처리 방식

공용부는 실제 세대 동·호가 아니므로, DB 내부에는 전용 기술 대상 COMMON / 0000을 만들고 실제 발생 장소는 세션의 inspection_kind=COMMON_AREA, common_area_label에 저장하도록 구현했습니다. 이는 기존 사진, 의견, AI 분류, 완료·재전송, 갤러리 기능을 그대로 재사용하면서 세대 통계와 공용부를 구분하는 방식입니다.

3. 적용 절차

cd D:\AI_projects\Apartment_Defect_AI
.\scripts\setup_local_field_db.ps1

# 기존 Field API를 Ctrl+C로 종료한 뒤 다시 실행
.\scripts\run_field_postgres_server.ps1 -Port 8001

첫 명령은 로컬 PostgreSQL 암호를 묻습니다. 암호는 화면·보고서·DB 메타데이터에 기록되지 않습니다. 성공 시 003_common_area_inspections.sql이 적용되어 공용부 대상과 세션 컬럼이 생성됩니다.

4. 적용 후 즉시 검증

Invoke-RestMethod 'http://127.0.0.1:8001/v2/field/households/resolve?building_no=COMMON&unit_no=0000'
Invoke-RestMethod 'http://127.0.0.1:8001/v2/field/gallery/households'

첫 호출이 COMMON, 0000 정보를 반환하면 준비 완료입니다. 휴대폰에서 공용부·기타 하자 입력 → 발생 위치 입력 → 사진·의견 저장 → 세대점검 마감 순서로 완료한 후, 두 번째 호출 목록과 앱 하자DB에서 공용부·기타 / 공용부 기록 항목을 확인합니다.

5. 사진·의견 열람 보장 범위

완료된 공용부 세션은 하자DB 목록에 표시되며, 선택 시 하자별 촬영사진·스티커/메모 사진·원문 의견·AI 추천·최종 분류를 함께 조회합니다. 전송 중이거나 미완료인 세션은 의도적으로 갤러리에 노출하지 않습니다.
