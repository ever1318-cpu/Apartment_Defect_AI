인트로 자동호출·정보블록 UI 개선보고서

버전 3.4 · 2026-07-25

1. 반영 결과

세대공간 자동 부르기와 동·호수 자동 부르기를 하나의 기능으로 통합하고, 인트로 정보 계층을 간결하게 정리했다.

AI 하자점검 → 동·호수 자동 부르기 → 동·호수 확인 → 단지·평형 확인 → 공간 선택

2. UI 변경 사항

항목변경 전변경 후
자동 호출 메뉴상단 ‘세대 공간 자동 불러오기’와 본문 ‘동·호수 자동 부르기’ 중복상단 제목 바로 아래의 동·호수 자동 부르기 하나로 통합
단지 정보단지명과 동·호수가 한 줄에 혼재첫 줄에 단지명과 평형, 둘째 줄에 현재 동·호수 표시
평형 정보정보 블록과 아래 ‘평형 · 84A-1’ 제목이 중복정보 블록의 평형만 유지하고 아래 중복 제목 삭제
평형 선택별도 제목 아래 선택 칩중복 제목 없이 84A-1·84B-1 선택 칩 유지

3. 표시 예시

울산다운지구 (평형:84A-1)
104동 204호

동·호수와 평형은 선택·자동 추천 결과에 따라 동적으로 변경된다.
