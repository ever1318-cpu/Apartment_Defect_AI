1. 진단 결론

카메라 화면의 SurfaceView가 화면 상호작용이나 수명주기 전환으로 파괴된 뒤에도 ViewModel의 열림 상태가 유지되어, 새 Surface에 카메라 세션을 재연결하지 못하는 구조를 확인했습니다.

2. 구현 내용

블랙아웃 자동 복구

Surface 파괴를 감지해 세션을 닫고 새 Surface 생성 시 다시 엽니다. 프레임 heartbeat가 5초 이상 중단되면 watchdog이 세션을 재시작합니다.

장시간 화면 유지

카메라 화면에서 FLAG_KEEP_SCREEN_ON을 사용하고 앱 pause/resume에 맞춰 카메라를 정리·재개합니다.

플래시 3단계

상단 버튼으로 자동 → 켜짐 → 꺼짐을 순환합니다. 촬영 요청에는 AUTO_FLASH, ALWAYS_FLASH, FLASH_OFF를 구분 적용합니다.

촬영 직후 재촬영

촬영 즉시 다음 화면으로 넘기지 않고 이미지를 크게 확인합니다. 점검자 또는 AI가 분간하기 어려우면 재촬영, 양호하면 이미지 사용을 선택합니다.

AI 저확신 재촬영

AI 결과가 비어 있거나 오류 또는 55% 미만이면 재촬영 권장 문구를 표시하고 고정 하단에 재촬영 버튼을 제공합니다.

평면도 현장 표시

세션에 저장된 모든 하자를 위험도 색상 핀으로 누적 표시합니다. 현재 위치는 3중 방사형 경광등이며 앵커가 없으면 인트로 선택 공간을 초기 위치로 사용합니다.
