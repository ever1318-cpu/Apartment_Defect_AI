1. 구현 결론

기존 AI 분석용 /v2 계약을 유지하면서 Android 현장 운영을 위한 /v2/field API 경계를 추가했다. 세대 점검 시작부터 앵커, 하자, RAW/STT 의견, 최종확인, 이미지 메타데이터, 집계, 마감, 오프라인 동기화까지 서버 계약과 PostgreSQL 저장 동작을 구현했다.

2. 현장 API

MethodEndpoint기능
POST/v2/field/sessions세대 점검 세션 생성
PUT/v2/field/sessions/{id}/anchor인트로 공간 좌표·앵커 방위 확정
GET/v2/field/sessions/{id}/summary전체·대기·확정·재검토 집계와 목록
POST/v2/field/sessions/{id}/complete세대 점검 마감
PUT/v2/field/defects하자 생성·수정, RAW/STT 의견 보존
POST/v2/field/defects/{id}/confirmation최종 분류·표준화 의견 확정
POST/v2/field/defects/{id}/media원본·근접·광각·추가 사진 메타데이터 등록
POST/v2/field/sync/batches통신 복구 후 오프라인 작업 일괄 동기화

3. 데이터 안전성

  • Idempotency-Key로 모바일 재전송 중복 저장 방지
  • If-Match revision으로 동시 수정 충돌 검출
  • 사진 바이너리와 DB 메타데이터 분리, SHA-256·크기·object key 기록
  • 입주민/STT RAW 원문과 LLM 표준화 의견을 별도 필드로 보존
  • 빈 세대 점검 마감 방지, 삭제 상태 하자 집계 제외
  • 응답과 로그에 DB 비밀번호·DSN을 포함하지 않음

5. 운영 반영 상태

운영 AWS RDS에는 적용하지 않음
현재 코드는 메모리 테스트 어댑터와 PostgreSQL 어댑터를 모두 제공한다. 다음 Gate에서 로컬 PostgreSQL에 마이그레이션을 적용하고 HTTP 통합시험을 거친 뒤, 별도 승인 후 스테이징 RDS에 적용한다.
