1. 이관 흐름

2. 포함·제외 대상

구분내용
포함PinSet-App, Apartment_Defect_AI, Two shot PinSet App, 최신 Debug APK, 전체 HTML 문서, 인수인계 문서

3. 현재 PC에서 실행

  1. Z: 드라이브를 연결하거나 네트워크 드라이브로 매핑한다.
  2. 최소 30GB 여유공간을 확인한다.
  3. PowerShell에서 다음 명령을 실행한다.
cd D:\AI_projects
powershell -ExecutionPolicy Bypass -File .\transfer_to_z_for_claude.ps1 -Mode Full
powershell -ExecutionPolicy Bypass -File .\verify_z_transfer.ps1

소스만 빠르게 옮기려면 -Mode Source를 사용한다. 전체 학습 결과를 이어서 분석하려면 Full이 권장된다.

5. 다른 PC에서 복원

  1. JDK 17, Android Studio·SDK, Python 3.11을 설치한다.
  2. PinSet-App\android\local.properties에 새 PC의 SDK 경로를 기록한다.
  3. Python 가상환경을 새로 만들고 pip install -e .을 실행한다.
  4. DB 환경변수와 AI API 키를 새 PC에서 별도로 안전하게 설정한다.
  5. CLAUDE_HANDOFF.md와 개발가이드 인덱스를 Claude에 먼저 읽힌다.
  6. Android와 Python 전체 테스트를 실행해 기준선을 확인한다.

6. 주의사항

  • 현재 세션에서는 Z: 드라이브가 연결되어 있지 않아 실제 복사는 아직 실행하지 않았다.
  • PC 프로젝트 복사에는 휴대폰 Room DB 데이터가 포함되지 않는다.
  • Release 키스토어와 비밀번호는 별도 보안 매체로 전달해야 한다.
  • 환경변수나 비밀번호를 Claude 대화, 문서, Git에 붙여 넣지 않는다.
