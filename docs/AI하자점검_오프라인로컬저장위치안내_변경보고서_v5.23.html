오프라인 로컬 저장 위치 안내 변경보고서 v5.23

작성일: 2026-07-30

목적: 통신 불량으로 서버 전송이 완료되지 않아도 하자 기록이 안전하게 기기에 보관됐음을 점검자가 즉시 알 수 있게 합니다.

처리 방식

  1. 하자 의견, 분류 메타데이터, 사진은 우선 기기 내부 Room DB와 사진 폴더에 저장됩니다.
  2. 저장 후 0.9초 동안 서버 전송을 확인합니다.
  3. 전송 완료면 “서버 전송 완료”를 표시합니다.
  4. 전송 대기·실패면 “서버 전송 대기 · 로컬 저장 완료”와 함께 기기 내부 앱저장소/captures, 실제 파일명을 팝업으로 표시합니다.
  5. 네트워크가 복구되면 동기화 큐가 자동 재시도합니다.

보관 주의

사진은 앱 내부 저장소에 보관됩니다. 앱을 삭제하면 내부 저장소의 미전송 자료도 삭제될 수 있으므로, 현장 점검 중에는 앱 삭제나 앱 데이터 초기화를 하지 않습니다.
