1. 구현 결론

점검 ID·동호수·소유주 단일 입력에서 시작해 세대 도면과 공간을 선택하고 AI 하자분류 어시스턴트로 진입하는 1차 전체 흐름을 구현했습니다.

단일 입력 → 300ms 자동조회 → 세대·마스킹 소유주 확인 → 평면도·나침반 → 공간 선택 → 세션 활성화 → AI 하자분류

2. 반영 내용

새 시작 화면

앱 시작 목적지를 세대 자동조회 인트로로 변경했습니다. 별도 조회 버튼 없이 입력 정지 300ms 후 검색합니다.

도면·공간 문맥

내장 카탈로그에서 평면도와 공간 앵커를 읽고, 공간 선택 후 세대 세션을 자동 활성화합니다.

개인정보 최소화

검색 결과의 소유주명은 마스킹 표시하며, 조회 실패 시에만 기본도면 계속 진행을 제공합니다.

AI 화면 연결

선택한 세대·공간·도면 출처를 로컬 점검 문맥으로 보존하고 AI 어시스턴트 상단에 표시합니다.

홈 진입 보완

기존에 함수만 있고 노출되지 않았던 AI 하자분류 어시스턴트 진입 카드를 홈에 배치했습니다.

접근성·실패 경로

북쪽 방향 설명, 숫자 기반 상태, 기본도면 표식, 도면 실패 문구를 추가했습니다.

3. 운영 DB 연동 경계

현재 운영 세대조회 API의 URL·인증·응답 계약이 확정되지 않아 실제 개인정보 DB 호출은 하지 않습니다.

HouseholdLookup 인터페이스와 내장 CatalogHouseholdLookup 구현을 분리했습니다. 다음 단계에서는 인증된 API 구현체를 추가하고 DI에서 교체하면 화면과 상태 흐름을 유지할 수 있습니다. 내장 별칭과 샘플 도면은 UI 검증용이며 운영 데이터로 간주하지 않습니다.
