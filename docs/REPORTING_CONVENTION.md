# AI하자점검 HTML 보고서 관리 규칙

이 프로젝트의 향후 주요 질문·분석·설계 답변은 다음 규칙을 따른다.

1. 답변을 독립 HTML 보고서로 `docs/`에 저장한다.
2. 보고서는 결론, 근거, 방법·설계, 한계, 권장사항, 후속 질문을 포함한다.
3. 새 보고서 생성 시 `AI하자점검_개발가이드_Index1.0.html`에 주제별 목차를 추가한다.
4. 인덱스의 버전·기준일·보고서 수를 갱신한다.
5. DB 비밀번호, DSN, 접속문자열, 개인정보는 보고서와 인덱스에 저장하지 않는다.
6. 실제 산출 수치와 설계적 가설을 구분해 표시한다.

통합 인덱스 제목은 사용자 지정에 따라 `AI하자점검 개발가이드 Index1.0`으로 유지한다.
