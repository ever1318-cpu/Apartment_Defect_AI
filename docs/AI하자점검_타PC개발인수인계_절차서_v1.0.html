  • Apartment_Defect_AI/docs: UI/UX·운영·개발가이드 문서

제외 항목

.env, 암호, local.properties, .venv, .gradle, build, Android SDK, PostgreSQL 데이터, workspace/field-media, 사용자 사진, 학습 데이터셋과 모델은 전달하지 않습니다.

자동 복사

현재 PC에서 다음을 실행합니다.

cd D:\AI_projects\Apartment_Defect_AI
.\scripts\export_full_developer_handoff.ps1 -Destination Z:\WooMi_Haja_AI\DeveloperHandoff

대상 폴더에 Android와 백엔드 소스, HANDOFF_README.md가 생성됩니다.

새 PC 초기 구성

  1. JDK 17, Android SDK(API 35 이상), Android platform-tools, Python 3.11 이상, PostgreSQL 18을 설치합니다.
  2. PinSet-App/android/local.properties에 새 PC Android SDK 경로를 입력합니다.
  3. Apartment_Defect_AI에서 Python 가상환경과 패키지를 설치합니다: python -m venv .venv, .\.venv\Scripts\python.exe -m pip install -e ".[database,serving,test]"
  4. PostgreSQL 암호를 새 PC에서 설정한 뒤 .\scripts\setup_local_field_db.ps1을 실행합니다.
  5. .\scripts\run_field_postgres_server.ps1 -Port 8001으로 서버를 실행합니다.
  6. PinSet-App에서 .\scripts\build_field_e2e_debug.ps1 -ApiBaseUrl http://127.0.0.1:8001 -Install을 실행합니다.

검증

서버 http://127.0.0.1:8001/health가 PostgreSQL 상태를 반환하고, 휴대폰에서 사진 1건을 저장한 뒤 서버 갤러리 및 DB에서 확인합니다.
