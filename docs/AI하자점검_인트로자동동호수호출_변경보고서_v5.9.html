자동 동호수 호출 변경보고서 v5.9

작성일: 2026-07-29

반영 내용

  • 인트로 제목 아래의 동호수 자동부르기 표시와 추천·적용 메시지를 화면에서 제거했습니다.
  • 인트로 진입 후 3초 뒤 동호수 자동 추천을 시작하고, 추천 결과가 있으면 자동으로 적용합니다.
  • 설정 아이콘 안에 동호수 자동부르기 (3초 후 적용) 메뉴를 추가했습니다.
  • 인트로 하단 공용부 진입 버튼은 공용부/기타로 변경했습니다.

사용 흐름

인트로 진입 → 3초 대기 → GPS·최근 입력값 기반 동호수 추천 → 결과 자동 적용. 사용자는 별도 메시지나 적용 버튼을 조작할 필요가 없습니다.
