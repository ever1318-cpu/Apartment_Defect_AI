PostgreSQL 실기기 E2E 1단계 구현보고서

v1.1 · 2026-07-27

구현 내용

Android 디버그 APK에 로컬 FastAPI 주소를 주입하고, ADB reverse·서버 PostgreSQL 상태·APK 빌드·선택적 설치를 한 번에 점검하는 build_field_e2e_debug.ps1를 추가했습니다.

  • 서버 /health가 persistence=postgresql인지 확인
  • 인가된 Android 기기 1대인지 확인
  • localhost API는 ADB reverse 자동 설정
  • API 주소를 포함한 Debug APK 빌드
  • -Install 옵션 사용 시 기기 설치

실행 순서

# 창 1: PostgreSQL API 서버
cd D:\AI_projects\Apartment_Defect_AI
.\scripts\run_field_postgres_server.ps1

# 창 2: 폰 연결 후 APK 빌드·설치
cd D:\AI_projects\PinSet-App
.\scripts\build_field_e2e_debug.ps1 -Install

현재 검증 상태

PowerShell 스크립트 문법 검증 완료

현재 작업 환경에는 ADB 기기·실행 중 API 서버·DB 환경변수가 없어, 실제 폰→PostgreSQL 1건 저장 검증은 폰 연결과 DB 비밀번호 입력 후 수행해야 합니다.

현장 확인 기준

  1. 앱에서 사진을 촬영하고 하자 의견·분류를 저장합니다.
  2. 하자 상세의 동기화 상태가 “서버 저장 완료”인지 확인합니다.
  3. 서버 콘솔에서 sync batch 200 응답을 확인합니다.
  4. PostgreSQL 조회로 세션·하자 1건이 생성됐는지 확인합니다.

1단계 완료 조건

사진을 포함한 하자 1건이 폰의 Room 큐에서 COMPLETED 상태가 되고, PostgreSQL apartment_ai.defects에 동일한 client UUID·위치·의견이 저장되면 완료입니다. 사진 파일 객체 저장과 스티커·메모 사진은 다음 단계에서 구현합니다.
