인트로 자동추천·STT 의견 단순화 v4.7

세대 추천·앵커·마스터 로그인과 의견 확정 흐름 개선

1. 구현 결과

인트로 자동 세대 추천과 직접 하자 입력을 단순화하고, STT 원문이 사라지지 않는 의견 확정 흐름으로 변경했다.

2. 인트로

항목적용
제목27sp로 확대, 동·호수 자동 부르기를 다음 줄 우측 정렬
자동 추천5초 점멸 후 인접 세대 추천, 적용 버튼 10초 점멸 후 자동 확정
수동 입력동·호수 입력 즉시 대기 중 추천을 취소
앵커기본 거실, 실제 앵커 촬영 결과가 있으면 기존 결과 유지
직접 입력앵커 기준 선택 팝업 삭제, 기존 앵커 또는 거실 기준으로 카메라 이동
마스터MManager / MM 인증 시 전권 허용, 불일치 시 DEMO

3. 의견 상세

1. STT 문자화 → 2. 점검자 보완 의견 → 1+2 텍스트 AI 분석 → 이미지 AI 분석 → 3. 종합의견 확정 저장
  • STT 마감 후 인식 문장이 기록 박스에 유지된다.
  • 안내 문구를 기록 박스 위로 이동했다.
  • 별도 추가 의견란과 수정 저장 버튼을 제거했다.
  • 최종 버튼은 ‘의견 확정 저장’ 하나로 통일했다.
