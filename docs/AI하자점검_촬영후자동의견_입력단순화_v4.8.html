Apartment Defect AI · Android implementation

촬영 후 자동의견·입력 단순화 v4.8

별도 조작 제거와 점검자·AI 문구의 시각적 구분

1. 흐름

하자사진 촬영 → 위치·이미지 분석 완료 → 하자의견 입력창 자동 표시 → 점검자/STT 의견 → AI 자동 의견 → 종합의견 확정 저장

2. 입력 단순화

  • 촬영 후 ‘하자정보의견 상세’ 버튼을 누르지 않아도 의견창이 자동으로 열린다.
  • STT 기록과 직접 입력을 점검자 의견 · STT 문자 입력창 하나로 통합했다.
  • 별도 현장메모 입력창을 제거해 사용자 입력창을 점검자 의견과 종합의견 두 개로 축소했다.
  • 점검자 문구는 네이비, AI 자동생성 문구는 보라색으로 구분한다.
  • 점검자 의견 변경 후 0.7초가 지나면 텍스트 AI 의견을 자동 갱신한다.
